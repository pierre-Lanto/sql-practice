# SQL Practice

Exercices SQL réalisés avec PostgreSQL et DBeaver, dans le cadre de mon apprentissage de la data analyse .

## Outils
- PostgreSQL
- DBeaver Community

## Base utilisée
Base "boutique" : clients, produits, commandes, lignes_commande (script de création : creation_boutique.sql).

## Contenu
- semaine1.sql : SELECT, WHERE, ORDER BY, LIMIT, DISTINCT, LIKE, IN
- semaine2.sql : agrégations (COUNT, SUM, AVG), GROUP BY, HAVING, CASE WHEN
- semaine3.sql : INNER JOIN, LEFT JOIN, anti-jointure, sous-requêtes, CTE
- semaine4.sql : fonctions de fenêtre (RANK, ROW_NUMBER, SUM OVER, LAG)
